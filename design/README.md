## Токены

**Шрифты:** Golos Text (интерфейс), IBM Plex Mono (часы, суммы, номера документов).

| Назначение | Цвет |
|---|---|
| Фирменный синий (кнопки, акцент) | `#1F5FD1` |
| Ссылки / наведение | `#1A52B8` / `#143F8F` |
| Акцентный текст на светлом | `#1A4FB0` |
| Мягкий фон акцента | `#E6EEFC`, обводка `#C4D6F7` |
| Фон страницы | `#F4F6F8` |
| Поверхность | `#FFFFFF`, граница `#E3E8EC` |
| Основной текст | `#17222D` |
| Второстепенный текст | `#5D6D7C` |
| Тёмный блок (баланс, футер) | `#17222D` |
| Внимание (ждём заказчика) | фон `#FFF6E6`, граница `#F0DCB4`, текст `#7A5410` |
| Ошибка / просрочка | фон `#FDECEA`, текст `#8F2A1C` |
| Успех (оплачено, пополнение) | фон `#DFF2E3`, текст `#22663A` |

**Статусы заявок:** Новая — `#ECE6FB`/`#4B2F9A`; В работе — `#E3ECFC`/`#1A4FB0`; Ожидает заказчика — `#FFF1D9`/`#7A5410`; Выполнена — `#DFF2E3`/`#22663A`; Закрыта — `#EEF1F3`/`#4A5A68`.

**Форма:** радиус карточек 14px, кнопок и полей 10px, бейджей 99px; высота кнопок и полей не меньше 44px; ширина бокового меню 240px.

## Что осталось заполнить на лендинге

Все значения в квадратных скобках: телефон, email, адрес и часы работы, юрлицо с ИНН и ОГРН, цены и лимиты тарифов, условия хостинга.
