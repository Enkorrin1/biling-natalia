# Codari — рабочее пространство клиента и команды

Веб-система для заявок, согласования работ, командных задач, встреч, продаж и учёта услуг. Функциональные сценарии адаптированы из эталона; интерфейс использует самостоятельную оболочку Codari.

## Возможности

- Заявки, версии оценки, согласование часов, фактическое время, дополнительные часы, приёмка, возврат на доработку и повторное открытие с причиной. Общие заявки согласует владелец компании.
- Общий чат организации, ответы на сообщения, прочтение, файлы и создание заявки из переписки.
- Команда: функции, подразделения, руководители, ёмкость, права и область доступа, участники заявки, команды клиентов, отпуск и передача работы.
- Внутренние задачи: список/доска, исполнитель, проверяющий, сроки, блокировки, чек-листы, обсуждения, файлы, наблюдатели и история.
- Встречи: планирование, участники, повестка, публикация итогов и задачи по договорённостям.
- Продажи: этапы, следующий шаг, причина отказа и однократная передача в связанную задачу.
- Финансы: тариф, баланс часов, пополнения, счета, акты, операции, печатные формы, отметка подписания и отдельные права. Платное сопровождение учитывается отдельно с лимитом клиента и включается в акт. Публикация итогов командной встречи сама по себе не создаёт платных часов.
- Приглашения, активация, восстановление пароля, временный доступ владельца.
- Шаблоны, массовое и автоматическое одобрение по лимиту, ожидающие решения, напоминания, месячные сводки.
- База знаний, аналитика, CSV, внутренние заметки, быстрые ответы, Git-ссылки, webhook, Telegram/MAX, email, Web Push и PWA.

Оформление Codari: верхняя навигация, палитра индиго, собственная композиция входа, контекст слева в заявках и финансах, тёмная тема, мобильное меню и вертикальные записи финансовых документов. Лендинг и сбор заявок на демонстрацию сохранены.

## Запуск

Нужен Python 3.11+. Установите requirements.txt в виртуальное окружение. Задайте ADMIN_EMAIL и ADMIN_PASSWORD, затем выполните:

    python app.py bootstrap-admin
    python -m uvicorn app:app --host 127.0.0.1 --port 8000

Вход: http://127.0.0.1:8000/?login. База по умолчанию — data/app.db; APP_DB меняет путь. Вложения хранятся рядом с базой в каталоге <имя_базы>_attachments. Миграции выполняются при запуске. Перед обновлением рабочего окружения сохраните копию базы и вложений.

Биллинг включён по умолчанию. BILLING_ENABLED=0 отключает раздел и его API.

## Отдельная демонстрация

    python scripts/seed_codari_review.py
    python scripts/seed_codari_scenarios.py

Задайте в PowerShell:

    $env:APP_DB = "$PWD\output\codari-review.db"
    $env:BACKGROUND_JOBS = "0"
    $env:BILLING_ENABLED = "1"
    python -m uvicorn app:app --host 127.0.0.1 --port 8786

Аккаунты: admin@team.demo, developer@team.demo, pm@team.demo, sales@team.demo, devops@team.demo, client@team.demo. Демонстрационный пароль: TeamReview123! Данные вымышленные, рабочая база не заменяется.

## Каналы и проверки

Переменные описаны в .env.example; приложение читает окружение процесса. Файл примера не загружается автоматически.

Для ботов нужны токены, webhook, внешний HTTPS и worker: python -m bot.worker run. Для email — SMTP, отправитель, публичный URL, IMAP или входящий webhook и фоновые задачи. Для Web Push — ключ VAPID и разрешение браузера. Напоминания и сводки работают при BACKGROUND_JOBS=1. В демонстрации внешние доставки выключены.

    python -m unittest discover -s tests -v
    node --check web/main.js
    node --check web/team.js
    node --check web/tasks.js

Структура: app.py — основные сценарии и финансы; team_management.py — команда/встречи/сделки; task_tracker.py — задачи; company_chat.py — общий чат; mailer.py и web_push.py — доставка; bot/ — мессенджеры. Интерфейс: web/main.js, team.js, tasks.js; компонентные стили workspace.css и оформление codari.css.
